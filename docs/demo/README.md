# ChitMirror Pitch Deck — editable source

The 8-slide PowerPoint deck is generated as an editable Open XML presentation from this source script. All slide text and diagrams are editable native PowerPoint elements. The deck is a product narrative based on the current repository audit; workflow and outcome examples are labelled conceptual where implementation is missing.

Run with Windows PowerShell and Python available:

```powershell
powershell -ExecutionPolicy Bypass -File .\docs\demo\build_deck.ps1
```

Output: `docs/demo/ChitMirror_Pitch_Deck.pptx`.
